Turn-by-turn guidance for **Waze for BYD**, based on Waze 5.22.90.123.

### Changes

- Sends maneuver, metres to turn, next road, remaining route distance and
  remaining seconds through the stock DiLink 5 AMap adapter broadcast.
- Reads Waze's immutable cluster navigation state before its template
  instructions/ETA gate. Uses Waze's own converters; server flags are unchanged.
- Supports AndroidX Trip and cluster template callbacks as fallback sources.
- Sends changed frames immediately and repeats unchanged frames every five
  seconds. Ends guidance after 90 seconds without a source update.
- Clears guidance on cancellation, session loss, empty/loading source data and
  orderly shutdown. Recovers a stale card after process death on the next start.
- Keeps guidance binding independent of projection-display and map-overlay
  availability. Does not switch the instrument-cluster mode.
- Preserves package `com.waze`, versionCode `1030811` and the existing signing
  certificate. Source overlays leave shared decoded files intact.

No arrival-time text, lane guidance or SOME/IP output is sent. This transport
is specific to the stock `com.byd.amapservice` adapter on DiLink 5 / Android 12.

### Validation

- 60 conversion, lifecycle, keepalive, expiry and recovery checks passed on the
  JVM and Android API 35.
- Android tests verified the exact broadcast keys, types, package and flags;
  these tests do not send broadcasts.
- APK v3 signature, 16 KiB ZIP alignment and unchanged payload entries verified.
- Installed on the owner's parked DiLink 5 vehicle using an in-place update
  after verifying the installed signing certificate. UID and first-install time
  were retained; no uninstall or data reset was performed.
- Cluster handshake, lifecycle and 1920x720 surface delivery succeeded.
- State-observer callbacks and AMap broadcast sends were recorded on the car.
  The owner reported a visible arrow card with navigation in native Waze for BYD
  and confirmed that cancellation cleared the card on the cluster and HUD.

### Limitations

This is an experimental prerelease. Changing maneuvers and distance countdown
while driving, long-running stability, complete field rendering and windshield
HUD behavior still need validation. Parked checks do not establish those results.
If Waze's cluster pipeline does not emit fresh data, guidance expires rather than
leaving an old arrow. Abrupt process death can leave a card until the next start.
Multiple navigation apps can overwrite each other's stock guidance card.
Logged parked frames contained maneuver code `0` and a zero turn distance;
correct changing maneuver values still need a driving test.

During testing, the system crash buffer also recorded an AppCompat theme error
in Waze's route dialogs. This release does not modify those dialogs; the issue
needs separate reproduction. Google sign-in remains unverified.

The observer is specific to the SHA-256-pinned Waze input. Future Waze versions
require reviewing its internal names and hook before rebuilding.

### Update requirements

Update an existing modified `com.waze` only when its signing certificate matches
this build and its version is compatible. Official Waze uses a different key.
Do not uninstall the app to perform an update: that erases local data.
