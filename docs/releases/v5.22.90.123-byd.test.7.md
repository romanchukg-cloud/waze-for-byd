# Waze for BYD 5.22.90.123 — test.7

An experimental update. The Instrument cluster button now looks like Waze's own
buttons, Waze's controls keep clear of the screen edges, and the cluster gets a
horizontal pointer offset and a zoom test.

## Changes

- **Instrument cluster button in Waze's style.** A 56 dp round button with a gauge
  icon, like the music and sound buttons beside it. It uses Waze's palette and follows
  Waze's map colours:
  - by day, white with a dark icon;
  - at night, black with a light icon.
- **Layering.** The button sits just above Waze's map layer:
  - Waze's menu, sheets and route screens cover it, as they cover Waze's own buttons;
  - it hides while the expanded ETA overview covers its place.
- **Screen edge margin (Waze buttons and panels).** 0–48 dp, default 16 dp, applied
  immediately.
  - It moves Waze's buttons, cards and panels away from the top, left and right edges.
    The map still fills the screen.
  - The bottom is not moved, so the ETA bar and the Where to? sheet stay on the
    navigation bar.
  - Waze adds its own 16 dp beside any side inset, so the sides are at least 16 dp once
    the margin is on.
  - 0 keeps Waze's own layout.
- **Side menu.** It now ends the margin above the navigation bar instead of running
  under it. Its last card scrolls into view.
- **Pointer horizontal offset (- left, + right).** −25 % to +25 % of the cluster width.
- **Cluster zoom test (experimental).** Zoom out and Zoom in buttons send a pinch to
  Waze's cluster map.
- **DiLink 3 AMap adapter (untested).**
  - Turn guidance goes to `com.example.amapservice` when only that service is found.
  - Otherwise it goes to `com.byd.amapservice`, as before.
  - The HUD status shows which one is used.
- **Reproducible builds.** The helper DEX uses a fixed ZIP date, so the same inputs and
  key give the same APK byte for byte.

## Validation

- **Reference DiLink 5.0 car:**
  - installed as an update that kept the UID and app data;
  - Waze restarted and the cluster session started;
  - the owner checked the round button, the panel, the top margin and the ETA bar
    staying on the navigation bar.
- **Android 13 emulator** at the car's resolution (2560 × 1440, 320 dpi):
  - the night colours of the button;
  - the button under the menu, route screens and ETA overview;
  - margins at 0, 16, 30, 32 and 48 dp, and the live slider;
  - ART bytecode verification.
- **JVM:** 61 guidance, 207 HUD and 65 cluster layout and theme checks.

## Remaining validation

**Not yet confirmed:**

- the button's day colours;
- whether the cluster map really zooms;
- the horizontal offset on the cluster;
- DiLink 3 and DiLink 5.1.

**Seen on the emulator, not yet checked in a car:** Waze can crash when the Go now
countdown ends in the ETA overview of a resumed drive. Waze's own first-use safety
dialog fails to open there. The build before test.7 does the same.
