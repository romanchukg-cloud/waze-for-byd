# Waze for BYD 5.26.0.0 — test.8

The patch moves from Waze 5.22.90.123 to Waze 5.26.0.0. The features are those of
[test.7](v5.22.90.123-byd.test.7.md).

## Changes

- **Waze 5.26.0.0 input.** Waze 5.26.0.0 is published only as a split bundle. The
  build uses the arm64-v8a, Android 10+ bundle, merged into one APK with APKEditor
  1.4.9 and pinned by SHA-256. See the [README](../../README.md#build).
- **ARM64 only.** That bundle has no ARMv7 libraries, so test.8 needs an ARM64 head
  unit. Its images are for 480 and 640 dpi; Android scales them on other screens.
- **New Waze internals.** These follow Waze's new obfuscated names:
  - the startup hook, the cluster map mode hook and the cluster state hook;
  - the turn and ETA converters;
  - the map night flag;
  - the zoom test probe.

  The Android for Cars interfaces that the cluster host uses are unchanged.
- **versionCode 2030742.** This is Waze's own versionCode plus 1,000,000:
  - test.8 installs as an update over the 5.22.90.123-based builds (1030811) and
    keeps app data;
  - Waze re-extracts its resources, which it does only when the versionCode grows.
- **Google Play source stamp removed.** It belongs to Google's signature and is
  invalid after re-signing.

## Validation

- **Signing:** the same certificate as earlier test builds
  (`50120cc57caa95d380fdf280e3a9c0853ed09ec8a617fe7bed33893c39b66276`).
- **Reference DiLink 5.0 car (Android 12L):**
  - installed as an update over test.7 that kept the UID and app data;
  - Waze started without crashes;
  - the cluster session was created, started and resumed, and Waze sent its
    navigation template;
  - Waze's map night flag was read;
  - the cluster display surface became available;
  - the Instrument cluster button sat in Waze's top row with the screen edge margin.
- **JVM:** 61 guidance, 207 HUD and 65 cluster layout and theme checks.

## Remaining validation

**Not yet confirmed:**

- the cluster map and turn guidance while driving with 5.26;
- the cluster colours;
- the HUD;
- the zoom test.

The Android 13 emulator stopped responding during this test round, so test.8 was
not run there.

**Going back.** A 5.22.90.123-based build can only be installed over test.8 with a
versionCode above 2030742.
