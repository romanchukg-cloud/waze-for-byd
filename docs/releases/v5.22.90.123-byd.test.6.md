# Waze for BYD 5.22.90.123 — test.6

An experimental update with an **Instrument cluster** settings panel that works like
Google Maps for BYD, and a cluster map that follows Waze's colours instead of always
being dark.

## Changes

- **Instrument cluster button** in the top row of the Waze map, left of the music and
  sound buttons. The panel applies changes immediately:
  - **Show map on instrument cluster:** turns the cluster map off without leaving a
    stale frame.
  - **Send turn guidance to cluster and HUD:** turns guidance off; an owned card is
    cleared within a second.
  - **HUD transport status.** On another DiLink 5.1 build whose HUD receiver passes
    every check, an opt-in switch appears: **Try standalone HUD on this firmware
    (experimental)**. It is off by default and applies after a restart.
  - **Pointer vertical offset**, from -25 % to +25 %. The default of 0 keeps the
    earlier layout.
  - **DiLink 5.1 cluster layout** settings, moved here from Support.
  - A link to **Support and diagnostics**.
- **Cluster colours follow Waze.** Waze hard-codes a dark cluster map. Test.6 uses
  Waze's Automatic mode instead, so the cluster follows Waze's map colour setting,
  **Apply for car display** and the head-unit theme, like the centre screen.
  Waze has no separate cluster style that can be switched live, so the panel offers
  no independent colour choice.
- **Route start** shows a straight-ahead arrow instead of BYD's finish flag.

## Validation

- **Signing and packaging:**
  - signature, 16 KiB alignment and ZIP integrity verified;
  - compared with test.5, only `classes6.dex` (the pinned cluster-map mode hook),
    `classes11.dex` and the signature entries differ;
  - same `com.waze`, versionCode 1030811 and signing certificate.
- **Reference DiLink 5.0 car:**
  - installed as an update that kept the UID and data;
  - the owner saw both the centre screen and the cluster switch with the head-unit
    theme;
  - Waze stayed running.
- **Earlier test.6 candidates:**
  - One reconnected the cluster session to change colours. That crashed Waze's native
    map engine, so this release never reconnects for colours.
  - Another changed the cluster map mode live. That had no visible effect, because
    Waze shares the base map style with the centre screen.
- **Android 13 emulator:** panel, map switch, pointer offset, guidance switch, the
  DiLink 5.1 layout and 120 diagnostics checks.
- **JVM:** 61 guidance, 207 HUD and 53 cluster layout and theme checks.

## For testers

Install as an update with the same signing certificate. BYD may keep the old Waze
process running after an update, so close Waze completely and open it again.

Then open **Instrument cluster** on the Waze map.
