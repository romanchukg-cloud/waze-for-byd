First test release of **Waze for BYD**, based on Waze 5.22.90.123.

### Included

- APK with the Waze for BYD application label and embedded cluster host.
- Waze's native cluster session on the BYD DiLink `XDJAScreenProjection` display.
- Package `com.waze`, versionCode `1030811`, Android 10+.
- A `.sha256` file to verify the download.

### Validation

The APK v3 signature and ZIP alignment for 16 KiB pages have been verified.
The signing certificate matches the previous local modified build,
cluster-test.1. Resources and native libraries are preserved byte for byte.
Compared with cluster-test.1, only the application label in the manifest has
changed; the host code remains the same.

### Installation and limitations

This is an experimental prerelease. The new APK has not yet been tested on a
physical instrument cluster. The previous build completed the cluster handshake
and received a `NavigationTemplate` on a virtual display; this does not confirm
how the map renders in a vehicle. The map currently stays open while the Waze
process is alive. Showing it only during navigation is not yet implemented.
Google sign-in and long-running stability have not been verified.

To update while preserving local data, the installed `com.waze` must use the
same signing certificate and a compatible version. Official Waze uses a
different signing certificate. Check the installed certificate and version
before installing. Do not uninstall the existing app to perform an update,
because uninstalling erases its local data.
